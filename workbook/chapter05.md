# Chapter 05 독자 워크북

## 요구사항에서 데이터 모델과 ERD 만들기

> 이 워크북은 요구사항을 데이터 구조로 바꾸는 사고 과정을 기록하기 위한 선택형 보조 자료입니다. ERD를 예쁘게 그리는 것보다 각 테이블·열·관계의 근거를 설명하는 데 집중합니다.

## 활동 표시

| 표시 | 의미 |
| --- | --- |
| **핵심 활동** | 요구사항 분석, 한 행 의미, 관계 문장과 ERD를 완성하는 활동 |
| **선택 활동** | 모델 수준, PostgreSQL DDL과 AI 초안을 확장하는 활동 |
| **심화 활동** | 복본·여러 저자·동시 대여·모델 변경을 검토하는 활동 |

처음 읽는 독자는 핵심 활동만 진행해도 충분합니다.

## 권장 실습 파일

```text
01_library_schema.sql
→ 02_library_seed.sql
→ 03_library_validation.sql
```

처음부터 다시 시작할 때만 `reset_library.sql`을 사용합니다. 기존 `library_schema.sql`, `library_seed.sql`, `library_validation.sql`은 호환용 파일이므로 번호 파일과 중복 실행하지 않습니다.
