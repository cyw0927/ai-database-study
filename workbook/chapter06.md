# Chapter 06 독자 워크북

## 정규화와 데이터 무결성으로 좋은 테이블 만들기

> 이 워크북은 정규형 이름을 암기하기보다, 서로 다른 사실을 분리하고 확정된 업무 규칙이 실제로 동작하는지 검증하기 위한 선택형 보조 자료입니다.

## 활동 표시

| 표시 | 의미 |
| --- | --- |
| **핵심 활동** | 중복·이상·정규형·기본 제약조건을 직접 판단하는 활동 |
| **선택 활동** | `ALTER TABLE`, 삭제 정책과 부분 고유 인덱스를 확장하는 활동 |
| **심화 활동** | 후보키, 기간 중첩과 운영 마이그레이션을 검토하는 활동 |

처음 읽는 독자는 핵심 활동만 진행해도 충분합니다.

## 권장 실행 순서

```text
01_normalization_schema.sql
→ 02_normalization_seed.sql
→ 03_normalization_compare.sql
→ 04_add_integrity_rules.sql
→ 05_integrity_tests.sql에서 한 테스트씩 실행
```

현재 상태를 처음부터 다시 만들 때만 `reset_normalization.sql`을 사용합니다.
