## 23. 권장 해설

### 핵심 개념

```text
INNER JOIN은 일치하는 행만 반환한다.
LEFT JOIN은 왼쪽 행을 유지하고 일치하지 않는 오른쪽 컬럼을 NULL로 만든다.
오른쪽 조건을 ON에 두면 부모를 유지하면서 연결 대상을 제한할 수 있다.
COUNT(*)는 결과 행, COUNT(column)은 NULL이 아닌 값, COUNT(DISTINCT column)은 고유값을 센다.
활성 신청은 신청·수강중 3건이고 취소 제외 신청 이력은 완료를 포함한 4건이다.
```

### FILTER 예상 결과

```text
total_count = 5
requested_count = 2
learning_count = 1
active_enrollment_count = 3
completed_count = 1
cancelled_count = 1
active_recorded_amount = 340000
non_cancelled_recorded_amount = 440000
```

### 집계 함수와 NULL

```text
COUNT(*)와 COUNT(column)은 입력 대상이 없으면 0을 반환할 수 있다.
SUM·AVG·MIN·MAX는 입력값이 없으면 NULL을 반환할 수 있다.
COALESCE는 데이터 없음과 0이 같은 업무 표현일 때만 사용한다.
```

### 과대 집계

```text
강의와 신청을 JOIN하면 강의가 신청 수만큼 반복된다.
강의 가격 합계는 신청 JOIN 없이 강의 테이블 수준에서 계산한다.
SUM(DISTINCT price)는 서로 다른 강의의 같은 가격을 한 번만 합산할 수 있으므로 일반 해결책이 아니다.
```

### 대표 수정 SQL

```sql
SELECT
    c.id,
    c.title,
    COUNT(e.id) AS non_cancelled_count
FROM course_project.courses AS c
LEFT JOIN course_project.enrollments AS e
    ON c.id = e.course_id
   AND e.status <> '취소'
GROUP BY c.id, c.title
ORDER BY c.id;
```

### 활성 신청 검산

```sql
SELECT
    COUNT(*) AS active_enrollment_count,
    SUM(recorded_amount) AS active_recorded_amount
FROM course_project.enrollments
WHERE status IN ('신청', '수강중');
```

예상 결과는 `3`, `340000`입니다.
