## 12. 권장 해설

```text
- DB 게이트는 구조·데이터·SQL 증거이며 전체 프로젝트 완료와 다르다.
- PK·UNIQUE 자동 인덱스와 반복 조회용 업무 인덱스는 목적이 다르다.
- PUBLIC·직접 GRANT·멤버십·소유권은 권한의 서로 다른 경로다.
- access_scope는 데이터 값이고 실제 접근 통제는 Role·VIEW·RLS가 담당한다.
- 질문 단위 VIEW는 질문 없는 학생이나 튜터 차원을 자동 보존하지 않는다.
- SQL·pandas 교차 검증은 같은 스냅샷의 실제 결과를 비교해야 한다.
- 미실행 항목을 통과로 표시하면 완료 판단의 신뢰도가 무너진다.
```
