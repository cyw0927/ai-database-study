# Chapter 03 독자 워크북

## PostgreSQL과 DBeaver로 실습 환경 만들기

> 이 워크북은 Chapter 03을 읽은 뒤 자신의 PostgreSQL 환경과 실행 결과를 기록하는 선택형 보조 자료입니다. 처음 읽는 독자는 핵심 활동만 진행해도 충분합니다.

## 활동 표시

| 표시 | 의미 |
| --- | --- |
| **핵심 활동** | PostgreSQL 서버와 DBeaver 연결을 준비하고 기본 환경을 확인하는 활동 |
| **선택 활동** | macOS·Linux, Docker와 관리형 PostgreSQL을 사용하는 경우 참고할 활동 |
| **심화 활동** | 검색 경로, 읽기 전용 상태, 접속 변수와 최소 권한까지 확장하는 활동 |

비밀번호, 전체 접속 URL, 실제 API 키와 Access Token은 이 워크북, 화면 캡처와 공개 저장소에 기록하지 않습니다.
