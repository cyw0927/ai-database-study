## 23. 권장 해설

```text
실행 성공은 SQL 문법과 참조 가능성을 보여 줄 뿐 업무 요구사항 충족을 증명하지 않는다.
```

```text
전체 UNIQUE는 완료·취소 이력까지 막을 수 있다.
부분 고유 인덱스는 활성 상태만 제한한다.
```

```text
명시적 ID 입력은 IDENTITY 시퀀스를 자동으로 이동시키지 않는다.
```

```text
LEFT JOIN 오른쪽의 NULL은 <> 비교에서 UNKNOWN이 된다.
누락까지 찾으려면 IS DISTINCT FROM이나 명시적 NULL 조건을 사용한다.
```

```text
SQLSTATE는 오류 종류이고 constraint name은 실제로 차단한 규칙이다.
```

```text
오류 테스트는 잘못된 값을 차단하는지 확인하고 정상 경계값은 지나치게 강한 제약이 없는지 확인한다.
```

