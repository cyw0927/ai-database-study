- [ ] CRUD 업무 시나리오를 실행했다.
- [ ] UPDATE 전에 SELECT로 대상을 확인했다.
- [ ] DELETE 전에 SELECT로 대상을 확인했다.
- [ ] JOIN SQL을 작성했다.
- [ ] GROUP BY 또는 집계 함수를 사용했다.
- [ ] 대시보드용 SQL을 3개 이상 작성했다.
- [ ] 필요한 SQL 문법을 공식 문서 또는 지정 학습 사이트에서 검색했다.
- [ ] 검색한 예제를 현재 테이블과 열 이름에 맞게 수정했다.
- [ ] 실행 전 예상과 실제 결과를 비교했다.
- [ ] ERD와 주요 실행 결과 이미지를 첨부했다.
- [ ] 비밀번호, Token, 실제 개인정보가 포함되지 않았는지 확인했다.
