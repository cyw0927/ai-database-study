# Chapter 11 증거 화면 체크리스트

이 폴더에는 실제 DBeaver/PowerShell 화면만 넣습니다. 만들어 낸 화면은 증거로 쓰지 않습니다. 비밀번호, 전체 접속 URL, 개인정보, 백업 파일 내용은 캡처하지 않습니다.

권장 파일:
1. step03_security_lab.png — 기준 행 수, JOIN, 상태별 건수와 합계.
2. step06_permission_test.png — 허용된 SELECT/앱 작업과 거부된 작업. 실패 테스트는 문장 하나씩 실행.
3. step09_backup.png — pg_restore 목록 일부와 SHA-256. 실제 파일 경로와 민감한 내용은 가림.
4. step12_restore_validation.png — 복원 DB 이름과 검증 통과 결과.

현재 캡처는 없습니다. 실제 화면을 캡처한 뒤 위 이름으로 저장하고 답안에 링크를 추가합니다.
