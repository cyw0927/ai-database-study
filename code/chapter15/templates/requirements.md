# Chapter 15 요구사항 정의서

## 1. 확정 요구사항

| ID | 요구사항 | DB·분석 반영 | 검증 |
| --- | --- | --- | --- |
| P15-R01 | 학생은 질문을 등록한다 | `questions.student_id` FK | P15-V04 |
| P15-R02 | 학생 이메일은 공백이 아니며 정확히 같은 문자열은 중복되지 않는다 | CHECK·UNIQUE | P15-T03·T17 |
| P15-R03 | 튜터 이메일은 공백이 아니며 정확히 같은 문자열은 중복되지 않는다 | CHECK·UNIQUE | P15-T04 |
| P15-R04 | 질문 상태는 `open·answered·closed`만 사용한다 | CHECK | P15-T06 |
| P15-R05 | 질문에는 여러 답변이 가능하다 | questions 1:N answers | P15-Q05·P15-T24 |
| P15-R06 | 답변은 존재하는 질문과 튜터를 참조한다 | FK 2개 | P15-T08·T09 |
| P15-R07 | 질문과 학습 자료는 N:M 관계다 | `question_materials` | P15-V04 |
| P15-R08 | 질문이 없는 학생도 0건으로 조회한다 | LEFT JOIN 요약 VIEW | P15-Q02 |
| P15-R09 | 연결되지 않은 자료를 조회한다 | LEFT JOIN | P15-V04 |
| P15-R10 | 한 질문 안에서 자료 표시 순서는 중복되지 않는다 | 복합 UNIQUE | P15-T16 |
| P15-R11 | 실제 개인정보·비밀·운영 파일을 사용하지 않는다 | 가상 Seed·운영 점검 | P15-V06 |
| P15-R12 | 질문 1건 단위 분석 데이터셋을 제공한다 | `question_analysis_dataset` | P15-V07 |
| P15-R13 | 같은 스냅샷의 SQL과 pandas 핵심 집계가 일치한다 | 읽기 전용 교차 검증 | Python P15-V09 |

이메일 대소문자 정규화는 별도 정책입니다. 현재 UNIQUE는 정확히 같은 문자열만 차단합니다.

## 2. 설계 결정과 미확정 정책

| ID | 질문·결정 | 현재 처리 |
| --- | --- | --- |
| P15-D01 | 한 질문에 여러 답변 | 허용 |
| P15-D02 | 같은 튜터의 복수 답변 | 미확정, UNIQUE 추가 금지 |
| P15-D03 | 답변 등록 시 질문 상태 변경 | 명시적 트랜잭션 예제, 자동 트리거 없음 |
| P15-D04 | closed 질문의 추가 답변 | 미확정, DB 제약으로 고정하지 않음 |
| P15-D05 | 비활성 학생·튜터의 신규 작업 | 미확정, 애플리케이션 정책으로 보류 |
| P15-D06 | 분석 기간 | `[2026-01-01 00:00+09, 2026-06-01 00:00+09)` |
| P15-D07 | 삭제·보관 | FK RESTRICT, 자동 삭제 금지 |
| P15-D08 | 자료 `access_scope` | 업무 분류 값이며 실제 접근 통제는 별도 Role·VIEW·RLS 필요 |

미확정 정책은 AI가 임의로 UNIQUE, CASCADE, 트리거, RLS 또는 pandas 전처리 규칙으로 고정하지 않습니다.

## 3. 분석 질문

```text
P15-Q01 상태별 질문 수
P15-Q02 질문 없는 학생을 포함한 학생별 질문 수
P15-Q03 답변 없는 튜터를 포함한 튜터별 답변 수
P15-Q04 2026년 1~5월 월별 질문·답변·자료 수
P15-Q05 질문별 답변 수와 자료 연결 수
P15-Q06 첫 답변까지 걸린 시간
```

한 행의 단위:

```text
question_analysis_dataset = 질문 1건
student_question_summary = 학생 1명
 tutor_answer_summary = 튜터 1명
```
